# 审计问题修复记录

对应原审计：`project-audit-2026-10-07.md`。原报告保留为修复前快照。

## 已修复

- 展开 Diff 面板通配符导入，恢复 Checkstyle/verify。
- Cron 明确 5 字段 UNIX、6/7 字段 Quartz，拒绝零/负步长、越界值和未支持语法，正确处理星期与年份。计算限定到 2199 年。
- SQL 保护字符串、引用标识符、注释和 dollar 引号；XML 保留混合内容和 xml:space，安全配置失败时拒绝执行。
- JSON 增加语法、长度和嵌套校验；JWT 使用顶层 JSON claims，支持 aud 数组，明确未验签与缺少 exp 的含义。
- 正则后台执行，对输入访问设置 50 万微秒/200 万次访问预算、输入与结果上限，停止旧计算并限制匹配数。预算检查通过 CharSequence 传入 Java 正则；捕获嵌套导致的 StackOverflowError 后报告输入错误。
- Diff 后台执行，剩余矩阵上限 400 万单元；超出时输出有效的整段删除/新增。每份输入最多 200 万字符/5 万行，视图与复制只含最多 2000 行/20 万字符的预览，UI 明确标示。
- 便签、收藏和闹钟迁移至用户目录的 `config/understatus/documents`。数据有版本与 SHA-256 校验，临时文件同步后替换，保留上个成功版本备份。旧 Preferences 保留用于迁移恢复。便签保存失败阻止窗口自动关闭。
- 音乐 URL、封面、歌词和搜索采用请求代次；旧结果不覆盖新选择。窗口销毁会关闭播放器，关闭后迟到的 URL 不再启动播放。暂停保留解码器与流，恢复从当前位置继续。
- 状态栏重新挂载后重建任务资源；关闭后的编辑器回调不再重新附加文档监听器。隐藏番茄钟不暂停计时，计时依据真实经过时间。闹钟记录触发日期并补发最近五分钟内错过的事件。
- 天气位置缓存缩短到 30 分钟，缓存上限 128 条，过期后最多保留 6 小时；配置身份隔离缓存，清理代次阻止旧请求回填。状态栏显示过期标记；定位未完成可安全重试；刷新按钮跟随真实任务状态；窗口关闭后屏蔽图表和文本回调。
- 天气响应和解压结果限制 2 MiB，音乐 API 限制 2 MiB，封面限制 4 MiB/1600 万像素；修复音乐相对重定向与连接释放。天气不跟随重定向，避免认证头跨主机转发。
- 删除 `nbactions.xml` 中的签名口令。`keystore` 已从 Git 索引移除但保留本地文件，新增忽略规则。
