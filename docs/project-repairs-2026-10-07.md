## 明确的行为选择

- 保留 Swing、Maven、NetBeans API 及现有模块边界，局部修复高风险路径，没有迁移 UI 技术栈。
- Diff 超预算时采用有提示的粗粒度结果；Cron 只支持明确列出的语法；XML 优先保留内容空白；这些约束见 README。
- 最后一个音乐视图关闭后停止播放。未保存的便签和收藏保留于当前进程，保存失败需重试；不承诺在强制退出/断电后保留内存修改。
- 测试密钥只取消跟踪并保留本地文件，没有轮换密钥或重写历史。旧 Git 历史仍含该测试文件。
- 修复在隔离 worktree 中开发、逐项复核后同步回当前项目；保留用户原有改动，不自动提交或推送。
