# UnderStatus

面向 Apache NetBeans 的状态栏插件，集成开发工具、便签、天气、番茄钟、闹钟和 MP3 播放器。

[English](README.md) | **简体中文**

## 环境与安装

- 面向 Apache NetBeans 30 / RELEASE300 API；构建和运行插件均要求 **JDK 21 或更新版本**。
- Maven 3.8+；Windows、Linux、macOS 平台。CI 配置为 Windows/Linux × Java 21/25。

```bash
git clone https://github.com/schrodingerfish/under_status.git
cd under_status
mvn clean verify
```

在 NetBeans **工具 → 插件 → 已下载 → 添加插件** 中选择 **`target/under_status.nbm`**，按提示安装和重启。`verify` 执行 JUnit、Checkstyle、依赖字节码检查，并生成 `target/site/jacoco/index.html` 覆盖率报告。模块构建通过不等于已完成目标 IDE 的安装验收。

## 功能

| 模块 | 实际能力 |
| --- | --- |
| 状态栏 | 时钟、工作计时、JVM 内存、编辑器行列及编码、只读切换、一键格式化和显示配置。点击内存条刷新统计。 |
| 天气 | 和风天气实时、逐小时、逐日、降水、空气质量及生活指数；以所配置账号的接口权限为准。刷新失败保留可用缓存并标明过期数据。 |
| 文本工具 | Diff、严格 JSON 格式化、XML、SQL、Cron 预览、JWT 解析、Java 正则、哈希、编码、Base64/URL、时间戳及文本转换。 |
| 其他工具 | 多便签、计算器、测试数据生成和取色器；Hex/RGB 可编辑，HSL 为只读显示。 |
| 番茄钟与闹钟 | 可配置工作/休息时长，单次或按星期重复闹钟。隐藏番茄钟不会暂停计时；延迟回调只进入一个完整的新阶段；闹钟补触发最近 24 小时内最后一次符合条件的时间。 |
| 音乐 | 通过配置的 API 搜索和播放、收藏、同步歌词及 MP3 按帧暂停续播。工具箱和独立窗口共享播放会话；最后一个音乐视图关闭时停止播放，待保存的收藏继续写入。 |

## 工具语义与限制

- **Cron：** 分别处理 Unix 5 字段和 Quartz 6/7 字段的星期规则，支持列表、范围、名称和正整数步长。Quartz 日期/星期字段必须恰有一个 `?`；年份范围为 1970–2199，不支持的扩展语法明确报错。按本地日历时间预览，夏令时切换处不保证与具体调度器的触发次数一致。
- **正则：** 保留 Java 语法，在独立 JVM 中运行，堆上限 64 MiB，总时限 2 秒（含进程启动），超时或取消会终止子进程。表达式/替换串各最多 2,048 个 UTF-16 字符，输入 100,000、输出 200,000，最多展示 500 个匹配；替换超过 500 个匹配会报错。需要 IDE 运行时的 `bin/java` 和可写临时目录。
- **Diff：** 精确 LCS 的矩阵预算为 1,000,000 个单元格，超限时把未匹配区域显示为粗粒度删除/新增块并提示；每侧最多 20,000 行，按当前视图渲染。
- **文本计算：** 共享工具一般限制输入 250,000、输出 500,000 个 UTF-16 字符，个别工具有更严格限制；通过有界后台任务计算，旧结果不能覆盖新输入。
- **SQL/XML：** SQL 保留字面量、带引号标识符、参数和注释，属于词法格式化器，不承诺校验所有数据库方言。XML 禁用外部实体，保留文本和混合内容中的空白，因此不会激进删除所有标签间空格。
- **JSON/JWT：** JSON 拒绝非法输入、重复键、多余尾部值及过深嵌套；十进制 scale 限于 ±1,024，防止极端指数转换耗尽资源。JWT 时间限于 Instant 范围及纳秒精度；**不验签，不证明令牌真实可信**。
- **随机数据：** 密码使用 `SecureRandom`；验证码、手机号、地址和邮箱用于模拟测试。多个哈希算法在后台顺序计算。

## 配置与数据保存

在状态栏设置中配置显示项、计时、音乐 API Host、和风天气 Host/Key 及定位方式。天气能力取决于端点及账号权限；网络请求限制响应大小及超时。默认测试使用固定数据和本机回环服务器，不依赖公网音乐/天气接口。

普通配置使用 NetBeans Preferences；和风天气 API Key 使用 **NetBeans Keyring**，Preferences 本身不是加密凭据库。Keyring 的保护能力取决于平台提供者。

便签与音乐收藏分别保存到：

```text
<netbeans.user>/config/understatus/content/
```

脱离 NetBeans 时回退到 `<user.home>/.understatus/content/`。文件包含版本及校验和，以原子替换保存并保留上一版本备份；内容**不加密**，每个文件的序列化内容上限为 16 MiB。文件不存在时迁移旧 Preferences 内容并保留旧值作为备份；已保存的空文件不会重新载入旧内容。迁移 IDE 配置时请一并备份该目录。

多个便签视图共享文档，编辑后经过 500 ms 防抖在后台保存；收藏采用后台串行写入。保存失败会显示状态并支持重试，未保存编辑保留在当前 IDE 会话中。主文件和备份均无法读取时，先禁止编辑，防止空内容覆盖原数据。退出 IDE 前应确认保存成功。
